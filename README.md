Stem Prep is an interview help centered project made using node and react. 
It's ran by cd'ing into the backend folder and running (in bash) "node server.js".
The frontend is stored in the prepranked-frontend and ran with the command "npm run dev"
It currently boots locally and many of the API functions are commented out for demo/simplicity purposes.
The Layout and most of the code was made with anthropic's model Claude. 
There are 4 main pages being the login page, Main Dashboard, Interview question page, and a leaderboard page for the greater social aspect.
